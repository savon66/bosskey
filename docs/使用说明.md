# 老板键 BossKey

一个 Windows 免安装小工具：按一下热键，指定的程序（按 exe 匹配）瞬间从屏幕上和任务栏里消失；再按一下，原样回来。

> 从 [Releases](https://github.com/savon66/bosskey/releases/latest) 下载时文件名为 `BossKey.exe`（就是「老板键」），本地自己打包则输出 `老板键.exe`，两者完全相同。

## 快速上手（3 步）

1. 双击 `BossKey.exe`（第一次运行会出现在右下角托盘）。
2. 点 **从运行窗口选择** → 勾选要藏起来的程序 → **添加选中**（也可以选 **浏览 exe 文件** 或 **手动输入名称**）。
3. 选好组合键（默认 `Ctrl+Alt+Q`）→ 点 **保存并应用**。

之后任何时候按 `Ctrl+Alt+Q`：

- 第一次按：目标程序全部隐藏（任务栏里也看不到）
- 再按一次：全部恢复并置顶

## 两种动作

| 模式 | 效果 | 适合场景 |
|---|---|---|
| 完全隐藏（默认） | 窗口和任务栏按钮一起消失，像没开过 | 老板/同事走近，需要"秒消失" |
| 仅最小化 | 窗口缩到任务栏 | 只想快速腾出桌面，不介意任务栏还在 |

## 细节说明

- **按 exe 名称匹配**：填 `chrome.exe` 就会隐藏所有 Chrome 窗口，新开的窗口也自动算在内；不用配窗口标题。
- **关闭按钮不退出**：点窗口右上角 × 会收起到托盘，程序继续在后台待命。真要退出请用托盘右键 → **退出**，或界面上的 **退出** 按钮。
- **找不到托盘图标**：Windows 11 默认把新图标收进任务栏的 `^` 溢出区，点开就能看到蓝色小锁图标；拖到任务栏上可以常驻。
- **托盘右键菜单**：显示主界面 / 立即隐藏 / 恢复窗口 / 退出。
- **开机自启**：勾选后写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，开机后自动最小化到托盘。取消勾选即移除。
- **配置文件**：`%APPDATA%\BossKey\config.json`，纯文本可手工编辑。删除该文件即恢复默认。
- **出错日志**：`%APPDATA%\BossKey\error.log`（正常使用不会产生内容）。

## 注意事项

- 热键如果被别的软件占用，状态栏会提示"注册失败"，换一个组合键即可。建议保留至少一个修饰键（Ctrl/Alt/Shift/Win），避免误触。
- 只能隐藏**普通桌面窗口**。独占全屏游戏、部分带反作弊保护的程序、以及会立即自我重建窗口的软件可能不生效。
- 本工具不修改、不注入目标程序，只是调用 Windows 自带的显示/隐藏接口，退出时会自动把隐藏的窗口恢复。
- 单实例运行：重复双击只会提示"已经在运行"，不会出现两个热键冲突。

## 源码与重新打包

```
bosskey/
├─ bosskey.py      # 全部源码（单文件，纯 ctypes + tkinter）
├─ test_core.py    # 核心逻辑自测：枚举窗口 / 隐藏 / 恢复 / 热键注册
├─ bosskey.ico     # 图标
└─ 老板键.exe       # 打包产物
```

修改 `bosskey.py` 后重新打包（需要 Python 3.12，自带 tkinter）：

```bat
python -m venv .venv
.venv\Scripts\pip install pyinstaller pystray pillow
.venv\Scripts\pyinstaller --noconfirm --onefile --windowed --name BossKey ^
  --icon bosskey.ico --add-data "bosskey.ico;." bosskey.py
```

产物在 `dist\BossKey.exe`，改名为 `老板键.exe` 即可分发，无需安装 Python。
